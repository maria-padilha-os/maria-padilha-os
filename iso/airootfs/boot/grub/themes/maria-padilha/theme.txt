# Maria Padilha GRUB theme for the installed target.  Calamares installs GRUB
# for both UEFI and BIOS and writes GRUB_THEME in /etc/default/grub.  The
# palette is the same candle-red set as Plymouth and the greeter; no external
# pixmap, font file or artwork is referenced.  Font properties are deliberately
# omitted so GRUB uses its own built-in unicode font; a missing distro font
# must not make the menu unreadable.
